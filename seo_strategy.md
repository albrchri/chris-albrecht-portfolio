# SEO Strategy

## Site overview
Personal portfolio for Christopher J. Albrecht (Chris Albrecht), an AI-native strategic delivery leader
in global financial services. The site serves as a professional brand, credibility hub, and point of
contact for recruiters, executives, and professional contacts.

## Rendering mode
React SPA (Vite + Wouter). All public routes are fully client-side rendered. No SSR or SSG is present.
Social bots and AI crawlers only see the static `index.html` shell.

## Public routes
- `/` — Home / Portfolio (hero, philosophy, accomplishments, experience, credentials, contact)
- `/now` — Current focus areas
- `/projects/legacy-cloud-transformation` — Case study

- `/projects/major-trading-transformation` — Case study
